# Storyboard: LLM Wiki + Hermes Console asset pack

## Symbol Mapping Table
| Concept | Visual symbol |
| --- | --- |
| Human-owned thinking | Amber notebook with fingerprint seal |
| Agent-speed maintenance | Teal winged terminal robot sorting markdown cards |
| LLM Wiki compounding | Living graph-tree of linked markdown notes |
| Generic AI drift | Pale gray fog of bland paragraphs |
| Hermes Console | Terminal tab embedded inside Obsidian note |
| Selected-note context | Transparent JSON bridge carrying highlighted text |

## Assets

1. Cover / concept-story: “The Second Brain Gets Two Authors”
   - Danny in Obsidian vault protects amber notebook while Hermes tends linked markdown graph.
   - Shows origin story and thesis in one warm narrative scene.

2. Ohmsha explainer: “The Loop That Compounds”
   - Visual machine: brain dump -> selected note -> Hermes tools -> artifact -> wiki update.
   - Technical, gadget-like, dense but readable.

3. Four-panel strip: “Why Not Let The Agent Write Everything?”
   - Panel 1: human-only wiki decays.
   - Panel 2: agent-only wiki becomes generic fog.
   - Panel 3: split boundary appears.
   - Panel 4: compound graph grows.

4. Ligne-claire product scene: “Hermes Console Inside Obsidian”
   - Clean workspace shot of Obsidian note with embedded Hermes terminal tabs, selected context bridge, status dots.
   - Reusable product storytelling asset.
