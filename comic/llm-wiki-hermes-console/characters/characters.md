# Character Definitions

## Danny, the human operator
Modern writer-builder. Dark curly hair, short beard, black hoodie, focused warm expression. Carries an amber notebook labeled “voice + judgment”. Visual posture begins slightly hunched over messy notes, then opens as the wiki graph becomes organized. Represents taste, decisions, judgment, and lived context.

## Hermes, the agent
Small winged terminal robot, teal glowing screen face, compact metal body, tiny messenger wings, toolbelt with markdown cards, link-check icon, git branch icon, and checklist icon. Helpful but not cute. Represents agent-speed maintenance and action.

## Obsidian Vault
A living markdown library: purple-black stone shelves, graph constellations, glowing note cards, visible backlinks as thin lines. Represents the LLM Wiki as human-readable structure.

## Generic AI Fog
Pale gray fog made of bland paragraph fragments and repeated autocomplete shapes. It softens unique handwriting when uncontrolled. Represents generic AI drift.
