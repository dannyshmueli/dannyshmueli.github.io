# Source: LLM Wiki + Hermes Console blog asset pack

Blog thesis: A useful second brain needs two authors: the human who owns taste, decisions, and voice, and the agent that keeps the wiki current.

Story beats:
1. Danny starts with scattered brain dumps, product judgment, blog ideas, research links, and rough questions inside Obsidian.
2. The LLM Wiki preserves human-owned thinking in markdown while allowing agent-maintained research and context to grow around it.
3. Hermes reads the wiki, updates backlogs, drafts artifacts, moves tasks, checks links, and writes useful context back.
4. Hermes Console brings that loop into Obsidian: selected note context, terminal tabs, busy/idle status, bridge JSON, background completion.
5. The graph becomes more useful as work compounds: note -> agent task -> artifact -> wiki update.

Characters:
- Danny: human operator/writer, dark curly hair, short beard, black hoodie, warm but focused expression, holds a notebook labeled “voice + judgment”.
- Hermes: friendly but sharp agent avatar, small winged terminal robot with glowing teal screen face, carries markdown cards and tiny tool icons.
- Obsidian Vault: living library/graph environment, purple-black stone shelves, glowing markdown pages, node-link constellations.
- Generic AI Fog: pale gray fog made of generic paragraphs, tries to flatten voice; avoided by the two-author boundary.

Symbols:
- Human-owned layer: amber notebook, fingerprint seal, protected shelf.
- Agent-maintained layer: teal maintenance drones, citation threads, markdown cards.
- LLM Wiki: living graph-tree made of notes and links.
- Hermes Console: terminal window embedded inside an Obsidian note, with tabs and status dots.
- Context bridge: small transparent JSON bridge carrying selected text from note to Hermes.
