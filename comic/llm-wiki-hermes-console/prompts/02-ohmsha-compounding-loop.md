# 02 Ohmsha — The Loop That Compounds

Preset: ohmsha
Art: manga
Tone: neutral
Layout: dense technical explainer
Aspect: landscape

Create a dense technical knowledge-comic diagram called “The Loop That Compounds”. Use an Ohmsha-style gadget reveal: a transparent machine made of markdown cards and terminal panels.

Show five connected stages with visual flow arrows:
1. Raw brain dump: messy note cards, links, questions.
2. Selected context: highlighted paragraph lifted from an Obsidian note.
3. Hermes action: winged terminal robot runs tools, checks links, updates backlog, drafts artifact.
4. Shipped artifact: blog post, issue, plan, code change cards emerge from machine.
5. Wiki update: results flow back into the living LLM Wiki graph, making the next cycle stronger.

Avoid talking heads. Make the explanation mostly visual: gears, bridges, note cards, graph nodes, terminal tabs, checkmarks, citations. Include small readable labels: “capture”, “select”, “act”, “ship”, “write back”.

Style: Japanese educational technical manga, clean panel organization, visual metaphors, precise readable composition, neutral professional colors with teal and amber accents.

Shared character + symbol system:
Danny: modern writer-builder, dark curly hair, short beard, black hoodie, focused warm expression, amber notebook labeled “voice + judgment”.
Hermes: small winged terminal robot with teal glowing screen face, toolbelt holding markdown cards, checklist icon, link-check icon, git branch icon.
Obsidian Vault: purple-black markdown library with glowing note cards and graph-link constellations.
Human-owned layer: amber notebook with fingerprint seal.
Agent-maintained layer: teal maintenance cards, citations, backlinks.
LLM Wiki: living graph-tree of linked markdown pages.
Generic AI drift: pale gray fog of bland paragraphs, kept outside the protected shelf.
No copyrighted characters. No real brand logos except generic textual labels: Obsidian, Hermes Console, LLM Wiki. Use readable English text sparingly. No fake UI tiny gibberish except decorative markdown snippets.
